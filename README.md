# sumo-predict-updates

Public update endpoint for the **Sumo Predict** desktop app (source in the
private `sumo-stats` repo). `latest.json` here is the Tauri auto-updater
manifest, served via GitHub Pages at
https://dimagithub.github.io/sumo-predict-updates/latest.json
The signed `.app.tar.gz` artifacts are attached to this repo's Releases.
